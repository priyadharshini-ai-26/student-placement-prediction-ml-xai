# Student Placement Prediction using Machine Learning and Explainable AI

## About the Project
This project predicts whether a student is likely to get placed based on academic performance and skill-related inputs using Machine Learning.

## Features
- Student placement prediction
- Machine Learning model
- Explainable AI using SHAP
- Confusion matrix visualization
- Model accuracy graph

## Technologies Used
- Python
- Machine Learning
- SHAP (Explainable AI)
- Pandas
- Scikit-learn

## Project Files
- `app.py` – Main application
- `create_dataset.py` – Dataset creation script
- `shap_explain.py` – SHAP explanation script
- `model.pkl` – Trained model
- `accuracy_graph.png` – Accuracy graph
- `confusion_matrix.png` – Confusion matrix
- `shap_explanation.png` – SHAP explanation visualization

## How to Run
1. Install the required Python libraries.
2. Run the application using `python app.py`.

## Note
This project is intended for educational purposes. Predictions are estimates and should not be treated as guarantees of employment outcomes.
